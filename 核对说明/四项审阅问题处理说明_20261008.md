## 1. 补充受迫响应扫描及操作边界

新增了实际数值计算，而非仅修改措辞：在物理双模态模型上扫描 1–20 mT 的七档正弦磁场幅值、0.7–1.3 的频率比，采用三组初值及双向频率延拓，共 1,029 组独立初值计算和 686 组延拓计算。每组先舍弃 128 个受迫周期，再保留 64 个周期。诊断包括周期复现误差、变分方程、有限时间切向增长率和单周期 Floquet 矩阵。

所有采样响应均收敛为受迫周期运动；双模态 Floquet 谱半径为 0.803809–0.889055。本实验未找到拟周期或混沌转变，因此没有编造“混沌临界点”，也没有把 KAM 充分条件失效当作环面破裂。大挠度外推单独标记；0.1 rad 斜率筛查线是保守建模筛查约定，不是证明得到的模型有效性阈值。

同时补算了更直接的操作边界：完整 64 模态周期响应的端部峰值达到 4 mm 时，对应场幅如下。

| 频率比 | 稳态 4 mm 边界（mT） | 指定启动过程的 8 模态采样边界（mT） |
|---|---:|---:|
| 0.8 | 13.636163 | 8.651287 |
| 0.9 | 7.500495 | 5.188161 |
| 1.0 | 1.916849 | 1.916887 |
| 1.1 | 8.790914 | 5.766158 |
| 1.2 | 18.593557 | 10.445524 |

启动过程从静止开始，磁场乘以 `1-exp(-(t/0.25 s)^2)`。该栏针对规定初态、爬升方式和有限采样时刻；不能作为任意启动方式的严格安全上限。稳态边界有模态数及相位加密、完整 64 模态 Radau 交叉检查；启动边界有步长、时长及输出加密和完整模型抽核。上述数值边界与后述连续时间清隙证明分别陈述。

位置：正文第 5 部分及 `sections/stability_boundary.tex`。代码、冻结输入、完整原始输出和运行说明：`reproducibility/reviewer_revision_20261008/stability_scan/`。

## 2. 从极窄 KAM 证明域补到非零物理误差容限

保留原有 `10^-220` 作用量半宽及其严格 KAM 测度结论，没有将它扩大为实际可操作误差。新增全节点物理能量证明，用初值能量椭球和误差条件下的输入功上界建立另一项清隙保证。

| 条件或结果 | 已落实数值 |
|---|---|
| 初始误差能量 `Q(error)` | 不超过 5 pJ |
| 该椭球蕴含的端部位置误差上界 | 56.006 μm |
| 角度、角速度、端部速度测量误差 | 1 mrad、0.01 rad/s、0.1 mm/s |
| 力和磁场乘性执行误差 | 各 1% |
| 力和磁场加性执行误差 | 0.5 nN、0.05 μT |
| 保证时段 | 4 s |
| 加性误差预留能量 | 小于 0.09677917 nJ |
| 总能量上限 | 22.66 nJ |
| 整条中心线连续时间位移界 | 小于 3.898405 mm |
| 相对 4 mm 净清隙的剩余量 | 大于 0.101595 mm |

56.006 μm 是能量椭球的投影，不意味着所有位置、角度和速度误差都可以独立取各自最大值；初始化条件仍需全状态能量估计。传感和执行误差数值是确定性假设，不是实测硬件规格。

证明分别处理测量误差、乘性执行误差和加性扰动；后者用阻尼与逆质量矩阵界预算。实际输入上限在命令端预先降额。区间矩阵计算采用 256 bit，输出上下界定向取整；初始化误差直接对完整节点重构计算，没有忽略模态变换残差。

新增完整 64 自由度节点模型的 Radau 计算及十倍容差加密。精化运行最高物理能量约 21.744898 nJ，保存时刻的中心线 Bernstein 上界约 1.944144 mm；能量账本残差小于 3×10^-16 J。约 97.8% 的保存时刻安全约束处于激活状态，因此本结果支持误差下的清隙，不能据此声称仍保持原轨迹、原跟踪性能或精确 KAM 环面。连续时间保证来自功不等式证明，有限精度仿真用于检查实现。

位置：正文第 5 部分及 `sections/operational_tolerances.tex`。代码、证书、冻结输入和两套轨迹：`reproducibility/reviewer_revision_20261008/robustness/`。
