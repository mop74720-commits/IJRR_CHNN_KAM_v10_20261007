## 二、导师指定的论文框架

| 部分 | 必须承担的任务 |
|---|---|
| 1. 背景，约3–5页 | 说明实际问题、已有研究、尚待解决的问题及本文贡献，形成自然递进的研究叙述。 |
| 2. 辛差分与复Hamiltonian推导 | 给出辛差分格式的核心推导全过程，以及复Hamiltonian函数形式的推导。 |
| 3. 数值与逼近分析 | 分析辛差分的数值性质和复Hamiltonian的逼近，呈现五项比较。 |
| 4. KAM非退化与不变环面 | 将前述模型、误差和非退化条件连接到不变环面结论。 |
| 5. 对实际问题的指导 | 解释所得结果如何用于磁驱动、运动控制与操作约束，给出对应验证。 |
| 6. 结论、参考文献 | 凝练回答完成了什么、得到什么结果；参考文献置于最后。 |

五项比较在旧v1和现行稿中的对应是：R−GR、C−GC、R−C、GR−GC及交互差(GR−GC)−(R−C)。现行稿以R=BR、C=BC对应无固定二次先验的实/复模型，以GR、GC对应加入该先验的模型。这是现有稿件的比较设计记录。

需固定保留的澄清：

- 95%／96.5%是老师材料中的示意或预测值，用户已明确它们不是硬指标，也不是KAM定理必须达到的比例。
- 环面比例需要说明统计域、测度和判定方法；有限时间仿真比例与严格无限时间结论分别表述。
- 95%抽样置信水平、0.95能量系数等其他数字须按各自定义解释。
- 用户没有设定正文总页数硬上限。当前14页正文、40页补充是v10的现状，不是新的验收指标。
- 当前沿用IJRR/SAGE模板，最终投稿期刊尚未确定。
- 导师2026年9月2–3日意见由用户在本对话粘贴提供；它们的要求已列于上表，不能将后续自动生成的核对报告当作导师原文。

## 四、每轮改稿的验收清单

- [ ] 原始主线和导师六部分框架仍能在稿件中逐项定位。
- [ ] 每个新增或改变的数学主张有推导、适用条件和必要出处。
- [ ] 学习、证明、仿真与控制中的模型及拟合系数一致，或已解释它们的对应关系与误差。
- [ ] 核心公式完整、必要；没有通过删去关键假设或困难结果制造“精简”。
- [ ] 五项比较与相关实验使用实际数据，数据来源、指标定义和不利结果完整呈现。
- [ ] 95%／96.5%没有被重新设成验收指标；统计观察与数学保证的范围清楚。
- [ ] 本文贡献与外部定理/证明归属明确，新增或修改引用已核实原文。
- [ ] 叙述连贯、结论直接；纯防御、重复贡献解释和无信息量表达已删除。
- [ ] 英文稿、英文补充和中文说明独立；编译、引用、图表及排版检查通过。
- [ ] 修订版本、配套数据、验证范围、备份及归档位置明确，未完成项能具体定位。
